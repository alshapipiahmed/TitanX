# TITAN X GYM

موقع تعريفي لنادي Titan X مبني باستخدام React وVite، مع واجهة عربية من اليمين إلى اليسار، وهوية زرقاء وسوداء، ومعرض صور للنادي.

## التشغيل المحلي

تأكد من تثبيت Node.js، ثم افتح الطرفية داخل مجلد المشروع الذي يحتوي على `package.json` ونفّذ:

```bash
npm install
npm run dev
```

افتح الرابط الذي يظهر في الطرفية، وغالبًا سيكون:

```text
http://localhost:5173
```

## بناء نسخة الإنتاج

```bash
npm run build
```

## بنية المشروع

```text
src/
├── assets/          الصور المحلية
├── components/      مكونات واجهة React
├── App.jsx          ترتيب الصفحة
├── main.jsx         نقطة تشغيل التطبيق
└── style.css        التنسيقات العامة والمتجاوبة
```

لا يتم تضمين `node_modules` داخل النسخة المضغوطة؛ يتم إنشاؤه تلقائيًا بواسطة `npm install`.
